# sdcHouse: Real-Time Virtual Space Platform

## Overview

sdcHouse is a real-time 2D virtual hangout space ("in-house 2D metaverse") with synchronized avatar movement, global chat, and WebRTC peer-to-peer audio/video.

## What Was Built

- Developed a real-time multiplayer web application using Next.js, verifying state synchronization, AABB collision detection, and WebRTC handshakes with local sync latency under 10ms across concurrent client sessions.
- Engineered a Socket.IO-based signaling server on Node.js/Express to manage live game state (player positions, chat) and broker peer-to-peer connections between users.
- Implemented WebRTC for direct peer-to-peer audio/video calls, removing media traffic from the server entirely by establishing connections directly via STUN.
