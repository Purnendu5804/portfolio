# riyal_auction: Real-Time Football-Team Auction Platform

## Overview

riyal_auction is a real-time, server-authoritative football-team auction platform. Captains bid live using virtual currency; spectators watch without signup.

## What Was Built

- Next.js frontend only (no API routes) paired with a standalone Bun WebSocket server holding authoritative in-memory state, solving concurrent-bid race conditions.
- Prisma/Postgres for persistence.
- Spectator mode requires no signup.
