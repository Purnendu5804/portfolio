# RCE Engine: Sandboxed Remote Code Execution

## Overview

RCE Engine is a Judge0-style sandboxed remote code execution engine.

Built with TypeScript, Express, BullMQ, Redis, dockerode, and Prisma.

## Current Status

Core execution engine is under active development.

## Ongoing Roadmap (Not Finished)

The DevOps layer is actively in progress and should be treated as a roadmap, not a completed feature:

- CI/CD via GitHub Actions (in progress)
- Prometheus / Grafana monitoring (in progress)
- Terraform infrastructure (in progress)

> Note: Anything marked in progress above is learning / work in progress, not completed.
