# RCE Engine: Sandboxed Remote Code Execution

## Overview

RCE Engine is a Judge0-style sandboxed remote code execution engine that runs untrusted user code inside isolated Docker containers.

## What Was Built

- Built a Remote Code Execution (RCE) engine that runs untrusted user code inside isolated Docker containers, enforcing a 128MB memory cap, a 64-process limit (fork-bomb protection), and no network access per submission.
- Designed an asynchronous execution pipeline with BullMQ and Redis that decouples submission intake from sandboxed execution, threading a single UUID across the API, job queue, and database so any component can resolve a submission's state independently.
- Created a 2-endpoint REST API (POST /submit, GET /submit/:id) with Express and Prisma/PostgreSQL to accept code submissions and expose execution status and results.
- Hardened the sandbox with defensive controls — execution timeouts with forced container kill, and a fresh throwaway container plus temp directory per submission — to safely execute arbitrary, untrusted code.
